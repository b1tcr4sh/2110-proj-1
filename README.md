## Campus Resource Reservation System

#Description

This is a C++ program implemented to help manage campus resources and student reservations. This program will help users idetentify availble resources, create and cancel waiting lists, and undo recent cancellations. 


## Features 

- Load resource information from a file. 
- Store resource information. 
- Display all resources. 
- Display resource availability.


## Data Structures 
- Stack: used to store cancelled reservations, restore the most recently cancalled reservation, and display cancellation history.
- Queue: used to add and remove students from waiting lits, display waiting list. 
- Linked List: Insert and remove reservations, traverse reservation records, and display reservation information.
- Vector: Stores the resources.
